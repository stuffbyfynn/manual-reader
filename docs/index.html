Manual Reader

Secure PDF Viewer for
Repair Manuals

A robust system for displaying repair guides in the browser with advanced security features, watermarking, and access control.

Explore Features Get Started
Django 5.x Tailwind CSS Alpine.js PDF.js MySQL Docker

Features

View-Only PDF Viewer

Canvas-based rendering without download or print functionality to protect your content.

Dynamic Watermarks

User email and timestamp automatically displayed on every page for traceability.

Secure Authentication

Only one active session per user allowed, preventing credential sharing.

Device Binding

Administrator approval required for new devices, adding an extra layer of security.

Invitation System

Registration only possible with admin-generated invitation codes.

Admin Dashboard

Full control over users, PDFs, and invitations from a central interface.

Installation

1 Clone the repository 

git clone https://github.com/your-username/manual-reader.git
cd manual-reader

2 Start with Docker Compose 

docker-compose up --build

3 Run migrations 

docker-compose exec web python manage.py migrate

4 Create superuser 

docker-compose exec web python manage.py createsuperuser
